# Конструктор иллюстраций

Первая версия реализует сборку по названиям предметов, три формата холста, переключение S/L, три раскладки, редактор слоёв, палитры и экспорт SVG. Этап подбора по заголовку запланирован после проверки раскладки на оригинальной библиотеке. [План разработки](PLAN.md)

## Запуск

Откройте `dist/offline.html` в Chrome. В автономную сборку уже включены исходники. После изменений пересоберите её командой `npm run build:offline`.

Для разработки выполните `npm run dev` и откройте `http://127.0.0.1:4173`. Для команд требуется Node.js 20 или новее. Устанавливать зависимости не нужно.

## Как подключить оригиналы

В проекте уже есть 46 SVG из секций L и S исходного макета. Каталог сопоставляет файлы с узлами Figma. Обновлённую библиотеку можно подключить через раздел «Исходники из Figma». Если отдельного файла нет, редактор показывает рамку и блокирует экспорт композиции с этим объектом.

- **Единый файл.** В Figma Desktop импортируйте `figma-export/manifest.json` через меню разработки плагинов, откройте исходный макет и запустите «Экспорт библиотеки иллюстраций». Плагин читает до 46 SVG и палитры, затем предлагает скачать JSON. Загрузите его через «Исходники из Figma». Для автоматической загрузки при каждом запуске положите файл в `dist/assets/library.json`.
- **Отдельные файлы.** Экспортируйте рамки в SVG и назовите их по ID узла, например `23-121.svg`. Их можно загрузить через редактор или положить в `dist/assets/`. Соответствие ID и вариантов находится в `dist/catalog.js`.

Импорт через редактор действует в текущей вкладке. Горизонтальный пример проверен повторным импортом в отдельный черновик Figma. SVG со внешними ресурсами и элементами вне поддерживаемого векторного набора редактор отклоняет.

## Палитры

Пользовательскую палитру можно загрузить как JSON-массив из восьми строк `#RRGGBB`. Порядок соответствует строкам таблицы Figma сверху вниз. В каждой строке сначала идёт цвет фона, затем цвет объекта.

```json
["#D7CDF5", "#F9ECB0", "#AA9BF0", "#F9A3AA", "#7864D7", "#FFE3E1", "#181817", "#FFFFFF"]
```

Режим «Исходные цвета» сохраняет заливки объектов. Перекраска сопоставляет заливки и обводки с точными значениями лавандовых образцов. Белые детали фона сохраняются. Для готовых схем сервис использует соответствующий фон из макета, для пользовательской палитры перекрашивает лавандовый фон.

## Подбор предметов по заголовку

Запустите Ollama и убедитесь, что модель видна в `ollama list`. Затем запустите сервис:

```bash
OLLAMA_MODEL=qwen3-local npm start
```

Если модель скачана под исходным именем, подставьте `qwen3:4b-instruct`. Откройте `http://127.0.0.1:4173`, введите «Идея складывается по частям» и нажмите «Подобрать предметы». Проверьте отмеченные предметы, при необходимости замените их и нажмите «Собрать варианты». Маршрут `POST /api/suggest` проверяет ответ модели по каталогу. В автономном HTML доступен ручной выбор.

## Render

В корне проекта есть `render.yaml` для бесплатного Node Web Service. При создании Blueprint укажите `OLLAMA_API_KEY` в настройках Render. Модель по умолчанию — `gpt-oss:20b` в Ollama Cloud. Для облачного запроса сервер просит ответ JSON и проверяет выбор по каталогу. Сервер ограничивает облачные вызовы до 150 за UTC-сутки в пределах одного запущенного процесса. При перезапуске счётчик сбрасывается. [Render Blueprint](https://render.com/docs/blueprint-spec)
